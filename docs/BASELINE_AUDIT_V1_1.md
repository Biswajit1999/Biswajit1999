# Profile evidence maturity: v1.1 baseline and result

This rubric evaluates the profile as research communication infrastructure. It
does not score the underlying science or the applicant.

| Dimension | Before | After | Evidence |
| --- | ---: | ---: | --- |
| Claim provenance | 35 | 96 | Seven questions and findings link to releases and source refs |
| Release traceability | 10 | 98 | Every verified record has an exact public tag |
| Epistemic boundaries | 30 | 96 | Project-specific limitations plus profile-wide disclosure |
| Portfolio coverage | 55 | 94 | Strongest completed public upgrades routed; unfinished work excluded |
| Reproducibility | 25 | 96 | Deterministic JSON-to-Markdown/CSV/SVG build |
| Automated verification | 10 | 94 | Five tests and Node 24 CI validation |
| Accessible communication | 78 | 94 | Direct-labelled SVG, text index, table, and machine source |
| Maintenance clarity | 45 | 92 | Pinned registry version and explicit refresh procedure |
| **Composite** | **36** | **95** | Equal-weight rounded mean |

The previous validator passed if three arbitrary x/y anchors and one citation
existed. It did not connect profile claims to results, releases, revisions, or
limitations; it had no tests or CI. The new score is high because those
communication controls are now inspectable and fail closed. It is not a claim
that the scientific portfolio became 2.6 times better.
